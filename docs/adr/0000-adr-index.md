# Indice de ADRs

> ADRs sao geradas via `/architect`. Cada ADR documenta uma decisao arquitetural aceita pelo time.

## Como usar

1. Rode `/architect` para criar ADRs interativamente
2. O agent sugere boas praticas de mercado como default
3. Decisoes incomuns sao questionadas e precisam de justificativa
4. Cada ADR inclui uma secao "Regras para Validacao" usada pelos agents de checagem

## Templates Disponiveis

Consulte `docs/adr/templates/` para ADRs pre-definidas baseadas em boas praticas:

- `universal/` — Principios universais (SOLID, naming, complexity)
- `backend-patterns/` — Patterns backend (Clean Arch, DDD, Repository, etc.)
- `frontend-patterns/` — Patterns frontend (Feature-first, Forms, Routing, etc.)
